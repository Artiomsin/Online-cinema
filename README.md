🎬 Онлайн‑кинотеатр
Веб‑приложение «Онлайн‑кинотеатр» для просмотра фильмов онлайн, управления пользователями и подписками. Стек: NestJS (TypeScript), Vue 3 (TypeScript), PostgreSQL + Drizzle ORM.

📖 Описание
Приложение поддерживает:

Авторизацию и роли пользователей (JWT).

Управление фильмами, жанрами, актёрами.

Подписки и избранное.

Историю просмотров и отзывы.

Персонализацию и рекомендации.

Админ‑панель для управления контентом и пользователями.

⚙️ Установка проекта
bash
# Клонирование репозитория
$ git clone <url>

# Переход в папку проекта
$ cd online-cinema

# Установка зависимостей
$ npm install
▶️ Запуск Backend (NestJS)
bash
# режим разработки
$ npm run start

# режим наблюдения (watch mode)
$ npm run start:dev

# режим продакшн
$ npm run start:prod
💻 Запуск Frontend (Vue 3)
bash
# переход в папку frontend
$ cd frontend

# установка зависимостей
$ npm install

# запуск dev-сервера
$ npm run dev
🗄️ Настройка базы данных (PostgreSQL + Drizzle ORM)
Создать базу данных cinema_db.

Настроить подключение в .env:

Code
DATABASE_URL=postgres://user:password@localhost:5432/cinema_db
Применить миграции:

bash
$ npm run db:migrate
🧪 Тестирование
bash
# модульные тесты
$ npm run test

# e2e тесты
$ npm run test:e2e

# покрытие тестами
$ npm run test:cov
🚀 Деплой
Для деплоя в продакшн:

Настроить переменные окружения (.env).

Использовать Docker или облачную платформу (например, AWS, Heroku).

Для NestJS см. документацию по деплою.

📚 Основные интерфейсы
Главная страница — список фильмов, поиск, фильтрация.

Страница фильма — описание, актёры, жанры, отзывы, кнопка «Добавить в избранное».

Профиль пользователя — данные, подписка, избранное, история просмотров.

Админ‑панель — управление пользователями, фильмами, жанрами, актёрами.
