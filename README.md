# Руководство пользователя (User Manual)

## Назначение

Приложение «Онлайн‑кинотеатр» предназначено для просмотра фильмов онлайн, управления подписками и персонализацией контента. Оно доступно как для обычных пользователей, так и для администраторов.

## Авторизация

- Введите логин и пароль.
- Если аккаунт активен, откроется главная страница.
- В зависимости от роли (пользователь или администратор) интерфейс будет различаться.

## Профиль пользователя

- Просмотр и редактирование личных данных (ФИО, email).
- Проверка статуса подписки.
- Просмотр списка избранных фильмов.
- История просмотров с возможностью продолжить просмотр.

## Работа с фильмами

- Просмотр каталога фильмов.
- Поиск по названию.
- Фильтрация по жанрам и странам.
- Просмотр карточки фильма: описание, год выпуска, актёры, жанры, рейтинг.
- Добавление фильма в избранное.
- Оставление отзыва и рейтинга.

## Избранное

- Добавление фильма в избранное через кнопку на странице фильма.
- Удаление фильма из избранного.
- Просмотр списка избранных фильмов в профиле.

## Просмотры

- Начало просмотра фильма.
- Автоматическое сохранение позиции останова.
- Продолжение просмотра с того же места.
- Просмотр истории просмотров.

## Отзывы

- Добавление текста отзыва и выставление рейтинга.
- Просмотр отзывов других пользователей.
- Средний рейтинг фильма рассчитывается автоматически.

## Подписки

- Просмотр доступных тарифов.
- Оформление подписки.
- Проверка статуса (активна/завершена).
- Продление или завершение подписки.

## Фильтрация по региону

- Фильтрация по языку.
- Фильтрация по стране производства.
- Просмотр популярных фильмов в вашем регионе.

## Персонализация

- Рекомендации на основе избранного.
- Уведомления о новых фильмах в любимых жанрах.
- Подборка «Похожие на ваши избранные».

# Руководство администратора (Administrator Guide)

## Админ‑панель (для администраторов)

- Управление пользователями: создание, удаление, изменение данных, назначение ролей.
- Управление фильмами: добавление, редактирование, удаление.
- Управление жанрами и актёрами.
- Просмотр журнала действий пользователей.

## 🛠 Технический стек

- **Frontend:** Vue.js, Html, CSS.
- **Backend:** NestJS, typescript.
- **Database:** PostgreSQL.

### Установка и запуск

1.  **Запуск Бэкенда(NestJs):**
    ```bash
    установка зависимостей
    - npm install
    запуск в режиме разработки
    - npm run start:dev
    запуск в обычном режиме
    - npm run start
    запуск в продакшн-режиме
    - npm run start:prod
    Backend будет доступен по адресу: http://localhost:3000
    ```
2.  **Запуск Фронтенда(Vue.js):**
    ```bash
    Перейдите в папку frontend/online-cinema-frontend и выполните команды:
    установка зависимостей
    - npm install
    запуск dev-сервера
    - npm run dev
    -Frontend будет доступен по адресу: http://localhost:5173 (или другой порт, указанный в настройках Vite)
    ```

## 🔄 Типовой сценарий работы (Workflow) приложения «Онлайн‑кинотеатр»

- **Пользователь**: регистрируется → авторизуется → ищет фильм → смотрит → добавляет в избранное → оставляет отзыв → управляет подпиской → получает персональные рекомендации.
- **Администратор**: авторизуется → управляет пользователями → добавляет/редактирует фильмы, жанры, актёров → контролирует подписки → просматривает журнал действий и аналитику.

Приложение «Онлайн‑кинотеатр» обеспечивает удобный доступ к фильмам, подпискам и персонализированным рекомендациям.  
Обычные пользователи получают комфортный просмотр и управление избранным, а администраторы — полный контроль над контентом и пользователями.
